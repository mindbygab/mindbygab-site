# MIND by GAB — website

Static site for [MIND by GAB](https://www.mindbygab.com), a tech studio in Miami. Plain HTML/CSS/JS, hosted on GitHub Pages.

- `index.html` — the whole page
- `assets/css/style.css` — styles
- `assets/js/main.js` — interactions; settings at the top (contact email, form endpoint, book link)

The contact form sends to mindbygab@gmail.com through FormSubmit. The first submission triggers an activation email that must be confirmed once.
